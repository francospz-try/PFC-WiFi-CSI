¿Qué significa cada valor y la semilla?
Semilla
Número que fija las decisiones aleatorias para repetir el experimento. Aquí determina la selección de ejemplos de soporte y se pasa al entrenamiento. No es una nota ni la cantidad de datos. Repetirla con los mismos datos, configuración y entorno permite reproducir la selección.
k
Ejemplos etiquetados del destino usados por cada actividad para adaptar la predicción. k=0: sin adaptación; k=1, 5 y 10: con pocos ejemplos. Con cinco actividades, k=5 usa 25 ejemplos en total. La consulta permanece igual y sus ejemplos no se usan como soporte.
Exactitud (Accuracy)
Predicciones correctas divididas entre todas las predicciones.
Precisión macro
Para cada actividad: de las veces que el modelo dijo esa actividad, cuántas fueron correctas. Se promedian las cinco clases con el mismo peso.
Recall macro
Para cada actividad: de los ejemplos que realmente pertenecían a ella, cuántos detectó el modelo. Se promedian las cinco clases con el mismo peso.
F1 macro
Combina precisión y recall con su media armónica para cada actividad y luego promedia las cinco clases.

CSI real: baseline exploratorio por bloques temporales de una grabación por clase. No equivale a validación con sesiones independientes.
